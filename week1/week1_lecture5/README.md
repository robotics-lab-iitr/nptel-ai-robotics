# ROS2 Python Basics

This repository accompanies the lecture 5 of course "Introduction to Artificial Intelligence to Robotics".

## Contents

It contains three simple ROS2 Python examples introducing the fundamental communication concepts in ROS2.

* Basic ROS2 Node: node.py           
* Topic-based communication: publisher_subscriber.py
* Parameters, Services and Clients: service_client.py

## Prerequisites

- Ubuntu
- ROS2 (Humble/Jazzy)
- Python 3
- rclpy
